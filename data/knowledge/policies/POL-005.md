# Certificate Management Policy

## 1. Purpose

This policy defines requirements for managing TLS certificates across Novus Bank's systems, following repeated incidents caused by certificate failures (INC-2024-001, INC-2024-004).

## 2. Certificate Inventory Requirements

All production TLS certificates must be:
- Registered in the central certificate inventory (Vault `pki/certs/`)
- Associated with a named owner (individual and team)
- Configured with automated expiry alerts at 60, 30, and 7 days before expiry
- Subject to automated renewal where possible

**Prohibited**: Manual certificate management without registration in the inventory.

## 3. Renewal Standards

| Certificate Type | Renewal Method | SLA |
|-----------------|---------------|-----|
| Internal services | ACME automatic (Vault PKI) | Automated |
| Payment scheme connectors | Manual via PKI team | 30 days before expiry |
| API gateway (external) | ACME automatic (Let's Encrypt) | Automated |
| Open Banking (FCA directory) | Manual via FCA portal | 60 days before expiry |
| SWIFT client certificates | Manual via SWIFT portal | 60 days before expiry |

## 4. Automated Renewal Monitoring

Automated renewal jobs (cert-renewal, cert-rotator) must:
- Emit structured log events on SUCCESS and FAILURE (not just warnings)
- Alert on failure independent of certificate expiry date
- Retry with exponential backoff on transient PKI API errors
- Record the result in the certificate inventory

> **Incident lessons**:
> - INC-2024-001: cert-rotator failed silently on PKI error; no retry; no alert
> - INC-2024-004: cert-renewal job failed on PKI 503; no retry; certificate expired 30 days later
> Both are now resolved by this policy requirement.

## 5. Emergency Renewal Process

If a production certificate expires unexpectedly:
1. Activate HOLD_PAYMENTS if the affected service is payment-critical
2. Page PKI team via `#pki-emergency` (30-minute emergency SLA)
3. Follow RUN-007 emergency renewal procedure
4. File a post-incident review within 5 business days

## 6. Audit

Certificate inventory must be audited quarterly. Audit must verify:
- All active certificates are registered
- All automated renewal jobs are running
- Expiry alerts are correctly configured
- No certificates are within 30 days of expiry without a tracked renewal plan
