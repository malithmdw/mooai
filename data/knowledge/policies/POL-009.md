# Fraud Management Policy

## 1. Purpose

This policy defines Novus Bank's approach to fraud prevention, detection, and response across all payment channels and customer interactions.

## 2. Fraud Detection Controls

All payment channels are protected by layered fraud controls:

| Control | Description | Scope |
|---------|-------------|-------|
| ML fraud scoring | Real-time XGBoost/NN model scoring | All payments |
| Rules engine | Static velocity and pattern rules | All payments |
| Device intelligence | Fingerprinting and behavioural biometrics | Card and online |
| Transaction monitoring | Batch post-processing for pattern analysis | All accounts |
| Mule account detection | Network analysis of payment flows | All accounts |

## 3. Fraud Score Thresholds

Default thresholds (configurable by Fraud Operations — see ARCH-008):

| Payment Type | ALLOW | REVIEW | DECLINE |
|---|---|---|---|
| Card-not-present | < 0.7 | 0.7–0.9 | > 0.9 |
| Wire transfer | < 0.5 | 0.5–0.8 | > 0.8 |
| Faster Payment | < 0.6 | 0.6–0.85 | > 0.85 |

Threshold changes require Fraud Operations Manager approval and must be logged. Emergency overrides (as in INC-2024-009) must be documented with reason and review date.

## 4. Authorised Push Payment (APP) Fraud

Novus Bank is a signatory to the Contingent Reimbursement Model (CRM) Code and the mandatory PSR reimbursement scheme (effective October 2024):
- Victims of APP fraud reimbursed up to £415,000 per claim (joint receiving/sending bank responsibility)
- Claims must be assessed within 5 business days
- Sending bank liable for 50% of reimbursement (shared with receiving bank)

## 5. Model Performance Requirements

| Metric | Minimum Standard |
|--------|----------------|
| Card-not-present false positive rate | < 0.5% per month |
| Wire fraud false positive rate | < 0.1% per month |
| True positive rate (fraud caught) | > 85% |
| Model retrain cadence | Quarterly minimum |

> **Model drift incident**: INC-2024-009 — false positive rate reached 18% due to bank holiday pattern shift. Required emergency threshold adjustment. Drives requirement for seasonal features in model training.

## 6. Fraud Reporting

- Monthly fraud loss report to Risk Committee
- Quarterly fraud intelligence brief to FCA (Payment Fraud Report)
- Immediate notification to Payment Systems Regulator for systemic fraud events
