## 1. Q4 2023 Incident Review

Priya opened with a summary of Q4 2023: 3 P1 incidents affecting payments, all resolved within SLO. However, the pattern of certificate-related failures (2 of 3) is concerning.

INC-2023-047 (November) and INC-2023-062 (December) both involved certificate management failures. Aisha noted this is a systemic issue rather than individual incidents.

## 2. Recurring Root Cause Analysis

Aisha presented a root cause analysis across 12 months of payment incidents:

| Root Cause Category | Incident Count | % of P1s |
|--------------------|----|---|
| Certificate management failure | 3 | 33% |
| Connection pool exhaustion | 2 | 22% |
| Idempotency store failure | 2 | 22% |
| Dependency version mismatch | 2 | 22% |

**Key finding**: Certificate management failures are the single largest root cause category. The team agreed that a new Certificate Management Policy is required (action: Tom Brennan to draft POL-005 by 2024-03-15).

James noted the connection pool pattern also deserves attention — both cases (INC-2023-031, and one in Q3) were caused by missing database indexes. Proposed adding EXPLAIN ANALYZE checks to the PR review process.

## 3. Q1 2024 Reliability Objectives

Agreed OKRs for Q1 2024:
- **O1**: Eliminate certificate-related payment incidents → implement automated certificate monitoring independent of renewal job status
- **O2**: Reduce connection pool exhaustion incidents to zero → add staging database sizing requirement and slow-query CI gate
- **O3**: Idempotency store hardening → evaluate Redis WAIT command for synchronous replication on payment writes
