## 1. Conformance Test Results

Raj presented the results of the Open Banking conformance suite test run (2024-03-15):
- 98.7% pass rate (previous: 97.2%)
- 3 failing tests: all in the PISP payment status callback path
- Status callback failures do not block payment initiation but may cause TPP reconciliation delays

Action: Raj to fix callback path by 2024-04-30.

## 2. INC-2024-008 Compliance Implications

Fatima presented the compliance analysis of INC-2024-008 (rate limiter misconfiguration locking out all TPPs for 76 minutes):

**Assessment**: The 76-minute lockout potentially breaches the PSD2 RTS requirement that banks must not "create unnecessary obstacles" for TPPs. However, the incident was unintentional, rapidly remediated, and no TPP suffered financial loss.

**Decision**: File a proactive disclosure with the FCA. Fatima will prepare the notification by 2024-03-31.

**Engineering action**: James to implement mandatory smoke test after any api-gateway configuration change (JIRA OB-120).
