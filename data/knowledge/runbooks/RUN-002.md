# Payment Gateway Operational Runbook

## 1. Purpose

Step-by-step procedures for operating, diagnosing, and recovering the payment gateway. See ARCH-003 for architecture context.

## 2. Health Checks

```bash
# Overall payment gateway health
curl -s https://payment-gateway.novusbank.internal/health | jq .

# Connection pool status
kubectl exec -n payments deploy/payment-gateway -- \
  python -c "from app.health import pool_stats; print(pool_stats())"

# Idempotency store connectivity
redis-cli -h redis-idempotency.novusbank.internal -p 6379 PING
```

## 3. Activating HOLD_PAYMENTS

The HOLD_PAYMENTS circuit breaker stops all outbound payment submission while allowing new requests to be queued. Use this when:
- Sanctions screening is unavailable
- Idempotency store is in failover
- Suspected duplicate payment event in progress

```bash
# Activate hold (CAUTION: stops all payments)
kubectl exec -n payments deploy/payment-gateway -- \
  curl -X POST http://localhost:8080/admin/circuit/hold_payments/activate \
  -H "Authorization: Bearer $ADMIN_TOKEN"

# Verify hold is active
kubectl exec -n payments deploy/payment-gateway -- \
  curl http://localhost:8080/admin/circuit/hold_payments/status
```

**Deactivate after root cause confirmed resolved:**
```bash
kubectl exec -n payments deploy/payment-gateway -- \
  curl -X POST http://localhost:8080/admin/circuit/hold_payments/deactivate \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

## 4. Scheme Connector Health

```bash
# FPS connector status
kubectl get pods -n payments -l app=fps-connector

# SWIFT gateway status  
kubectl get pods -n payments -l app=swift-gateway

# Check connector TLS certificate expiry
kubectl exec -n payments deploy/fps-connector -- \
  openssl s_client -connect fps.vocalink.com:443 2>/dev/null | \
  openssl x509 -noout -dates
```

## 5. Certificate Renewal Emergency Procedure

If a scheme connector certificate expires (as in INC-2024-001, INC-2024-004):

1. Contact PKI team immediately: `#pki-emergency` Slack or pki-oncall@novusbank.internal
2. Request emergency certificate via PKI fast-track (30-minute SLA)
3. Deploy new certificate:
   ```bash
   kubectl create secret tls fps-connector-tls \
     --cert=new-cert.pem --key=new-key.pem \
     -n payments --dry-run=client -o yaml | kubectl apply -f -
   kubectl rollout restart deployment/fps-connector -n payments
   ```
4. Verify certificate installed correctly
5. File JIRA for cert-renewal job investigation

## 6. Duplicate Payment Detection and Response

If duplicate payments are suspected (as in INC-2024-011):

1. Activate HOLD_PAYMENTS immediately
2. Query idempotency store for collisions:
   ```bash
   redis-cli -h redis-idempotency.novusbank.internal \
     SCAN 0 MATCH "idmp:*" COUNT 1000
   ```
3. Contact DBA team to cross-reference transaction-ledger
4. Initiate reversal process for confirmed duplicates (see RUN-006 for SWIFT reversals)
