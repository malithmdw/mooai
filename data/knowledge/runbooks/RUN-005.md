# Bacs Submission Service Runbook

## 1. Purpose

Procedures for operating the Bacs Direct Debit and Direct Credit submission service. Bacs operates to strict cut-off windows; late submissions incur next-day settlement delay.

## 2. Daily Submission Schedule

| Step | Time (UTC) | Description |
|------|-----------|-------------|
| File generation begins | 16:00 | bacs-submission-service generates AUDDIS file |
| Validation | 17:30 | Pre-submission validation against Bacs schema |
| Submission window opens | 18:00 | File transmitted to Vocalink |
| Submission cut-off | 22:30 | Hard cut-off — no late submissions accepted |
| Bacs ACK received | 22:30–23:59 | ACK or NACK from Bacs central |

## 3. Pre-Submission Validation

**Always validate the submission file before transmitting.** The following checks are mandatory:

```bash
# Run Bacs AUDDIS schema validation
kubectl exec -n payments deploy/bacs-submission-service -- \
  python validate_auddis.py --file /tmp/submission-$(date +%Y%m%d).asc

# Checks performed:
# 1. Pure ASCII encoding (no multi-byte characters)
# 2. Record length = 100 characters per AUDDIS spec
# 3. Sort code format validation
# 4. Mandatory field completeness
# 5. Record count matches manifest
```

> **Encoding incident**: INC-2024-014 — submission rejected because file-writer v5.0 changed default encoding to UTF-8. Bacs requires ASCII only. Validation script now checks encoding before submission.

## 4. Investigating a NACK

If Bacs returns a NACK (rejection):

1. Download the NACK detail file from Bacs portal
2. Parse error codes:

| Error Code | Meaning | Action |
|-----------|---------|--------|
| E001 | Invalid sort code | Check source data; correct and resubmit |
| E002 | Invalid account number | Check source data; contact customer |
| E010 | Character encoding error | Re-encode file as ASCII; resubmit |
| E020 | Record count mismatch | Regenerate file; validate count |

3. If resubmission is within cut-off window: fix and resubmit
4. If after cut-off: file P2 incident; notify Operations team

## 5. Emergency Resubmission

```bash
# Regenerate submission file with corrected encoding
kubectl exec -n payments deploy/bacs-submission-service -- \
  python generate_auddis.py --date $(date +%Y-%m-%d) --encoding ascii

# Validate
kubectl exec -n payments deploy/bacs-submission-service -- \
  python validate_auddis.py --file /tmp/submission-$(date +%Y%m%d).asc

# Submit (only if within cut-off window)
kubectl exec -n payments deploy/bacs-submission-service -- \
  python submit_auddis.py --file /tmp/submission-$(date +%Y%m%d).asc \
  --confirm
```
