# Open Banking API Runbook

## 1. Purpose

Operational procedures for the Open Banking API platform. See ARCH-007 for architecture context.

## 2. Health Checks

```bash
# Open Banking API health
curl -s https://openbanking.novusbank.com/health | jq .

# TPP registry status
kubectl get pods -n open-banking -l app=tpp-registry

# Rate limiter configuration (VERIFY UNITS ARE req/second, not req/minute)
kubectl exec -n open-banking deploy/api-gateway -- \
  cat /etc/nginx/rate-limit.conf
```

> **CRITICAL**: Verify rate limiter units after any api-gateway deployment. INC-2024-008 was caused by a req/min vs req/second unit mismatch that locked out all 47 TPPs. Correct value is `limit_req_zone $http_x_tpp_id zone=tpp_zone:10m rate=300r/s;`

## 3. Rate Limiter Configuration

Current rate limits (req/second per TPP):

```nginx
# /etc/nginx/rate-limit.conf
limit_req_zone $http_x_tpp_id zone=tpp_accounts:10m rate=300r/s;
limit_req_zone $http_x_tpp_id zone=tpp_payments:10m rate=60r/s;
limit_req_zone $http_x_tpp_id zone=tpp_tokens:10m rate=30r/s;
```

**Applying a rate limit change:**
```bash
# 1. Edit config in ConfigMap
kubectl edit configmap nginx-rate-limit -n open-banking

# 2. Test config
kubectl exec -n open-banking deploy/api-gateway -- nginx -t

# 3. Reload nginx (no downtime)
kubectl exec -n open-banking deploy/api-gateway -- nginx -s reload

# 4. Run TPP smoke test IMMEDIATELY after config change
kubectl exec -n open-banking deploy/open-banking-api -- \
  python tests/smoke/tpp_rate_limit_test.py
```

## 4. TPP Suspension

To suspend a TPP (e.g., compliance breach):
```bash
kubectl exec -n open-banking deploy/tpp-registry -- \
  python admin.py suspend-tpp \
  --fca-registration <FCA_REG_NUMBER> \
  --reason "Compliance breach — ref COMP-XXX" \
  --admin-token $ADMIN_TOKEN
```

Suspended TPPs receive HTTP 403 with code `TPP_SUSPENDED` on all requests.

## 5. Checking Active Consents

```bash
# Count active consents
kubectl exec -n open-banking deploy/tpp-registry -- \
  psql $CONSENT_DB_URL -c \
  "SELECT tpp_name, COUNT(*) FROM consents WHERE status='AUTHORISED' GROUP BY tpp_name;"
```

## 6. PSD2 Incident Escalation

If the Open Banking API is unavailable and TPPs are blocked:
1. Classify as P2 minimum (PSD2 requires banks not to obstruct TPP access)
2. Notify Open Banking compliance lead within 15 minutes
3. If outage > 1 hour: prepare FCA notification draft
